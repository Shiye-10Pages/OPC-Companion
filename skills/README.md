# OPC 伴侣 · Claude Skills

这里是「OPC 伴侣」配套的 Claude Skill —— 把 app 里的核心对话模式复刻成可在 Claude 生态(Claude Code / claude.ai / Claude Desktop)里直接使用的 skill。

## stoa-mirror · 斯多葛镜子

OPC 伴侣「斯多葛模式」的 Claude skill 版。当你焦虑、想法太多无从下手、自我否定、卡住、或想复盘时,它用斯多葛五模块框架(控制二分法 / 事实÷评判 / 灾难预演 / 顺势而为 / 美德复盘)把一团纠结坍缩成一个此刻可控的下一步动作——不打鸡血、不空安慰、不预测未来,只做你的镜子。

**安装(任选其一):**

```bash
# 方式一:拷贝整个目录到用户级 skills 目录
cp -R skills/stoa-mirror ~/.claude/skills/

# 方式二:claude.ai / Claude Desktop —— 把 skills/stoa-mirror/ 压成 zip 后在设置里上传
```

装好后,在对话里说一句「我卡住了,没状态」之类,它会自动现身。

## 它和 app 的关系

skill 复刻的是「魂」—— 斯多葛这套思考方法,纯对话即可体验。
而「壳」—— 全局热键随手记、菜单栏常驻、语音、计时、**可填写可存档的原生卡片** —— 只有 macOS 上的 OPC 伴侣 app 给得了。skill 是入口,app 是完整体验。
